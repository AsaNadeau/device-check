Device Check v2

Tests what Safari on this iPhone or iPad can do for a browser-based testing app. Nothing leaves this device.

How to run it

  1. Open this page in Safari. Tap Run checks, then Test camera, and save one reading below.
  2. Tap Share → Add to Home Screen. Open Device Check from the new icon.
  3. In the installed app tap Keep data, then Run checks again.
  4. Turn on Airplane Mode. Swipe the app closed, reopen it from the icon, and save another reading.
  5. Turn Airplane Mode off, reopen, tap Run checks, then Copy results.
